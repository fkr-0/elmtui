# Core Module Implementation Details

<!-- AI-IMPORTANCE:level=critical -->
## Technical Overview

The `core` module's implementation revolves around an efficient event processing mechanism. It typically involves one or more event queues, a dispatcher that routes events to appropriate handlers (often based on focus), and data structures for managing focusable elements and the current focus state.

### Event Loop Internals
- **Event Sources:** How events are received from the `platform` module (e.g., blocking read, callbacks, channels).
- **Event Queue:** Data structure used for the event queue (e.g., `sb-concurrency:queue`, custom list-based queue).
- **Processing Logic:**
    1. Dequeue event.
    2. Identify target (e.g., focused component, global handler).
    3. Invoke handler method/function.
    4. Handle special events (e.g., quit signals, focus change requests).
- **Thread Management:** The event loop often runs in its own thread, separate from the initial application thread.

### Event Dispatch Mechanism
- **Focus-Based Dispatch:** Events like key presses are typically sent to the currently focused component.
- **Global Handlers:** System for registering handlers for events that are not component-specific.
- **Message Propagation:** How messages generated by components are put back into the event system or handled directly.

### Focus Management Implementation
- **Data Structures:** How focusable elements are tracked (e.g., a list, a tree).
- **Focus Traversal Logic:** Algorithms for `next-focusable`, `previous-focusable` (e.g., based on tab order, spatial navigation).
- **`*current-focus*`:** A special variable or slot holding the currently focused component.
- **Focus/Blur Events:** How these events are generated and dispatched when focus changes.

## Development Guide

### Key Public APIs (Internal to Elmtui or for advanced users)
*   `send-event (event)` / `post-event (event)`: Adds an event to the main queue.
*   `add-event-handler (event-type handler-fn &key global-p target-component)`
*   `request-focus (component)`
*   `get-current-focus ()`
*   `register-timer (interval-ms callback-fn &key repeating-p)` (If timers are managed here)

### Important Notes
*   Avoid blocking operations within event handlers to keep the UI responsive. Use asynchronous tasks for long operations.
*   Be mindful of re-entrancy if event handlers can trigger new events.

### Extension Points
*   Defining custom event types.
*   Custom event dispatch strategies (if the system is designed for it).
