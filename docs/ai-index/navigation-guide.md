# Elmtui Documentation Navigation Guide

This guide provides several paths to help you navigate and understand the Elmtui project documentation. For a general starting point, see the [AI Index Overview](./overview.md).

## 1. Beginner's Path

For those new to Elmtui:
1.  Start with the [System Architecture Overview](../architecture/system-overview.md).
2.  Understand the [Core Architectural Concepts](../architecture/core-concepts.md).
3.  Review the [Setup Guide](../dev-guides/setup.md) to get your environment ready.
4.  Explore a simple module, e.g., [UI Module Overview](../modules/ui/overview.md) and its [Implementation Details](../modules/ui/implementation.md).

## 2. System Architecture Understanding Path

To grasp the overall architecture:
1.  [System Architecture Overview](../architecture/system-overview.md)
2.  [Core Architectural Concepts](../architecture/core-concepts.md)
3.  [Technology Stack](../architecture/tech-stack.md)
4.  [Module Dependencies](../architecture/module-dependencies.md)
5.  Deep dive into core modules like [Core Module Overview](../modules/core/overview.md) and [Platform Module Overview](../modules/platform/overview.md).

## 3. Feature Development Path

When developing a new feature or widget:
1.  Identify relevant modules (e.g., `ui`, `state`, `view`).
2.  Review their `overview.md` and `implementation.md` files. (See section 6 for a full list of module overviews; each overview links to its implementation).
3.  Consult the [Creating Widgets Guide](../dev-guides/creating-widgets.md).
4.  Refer to [Coding Standards](../dev-guides/coding-standards.md).
5.  Understand the [AI Documentation Guide](./documentation-guide.md) if you are also updating documentation.

## 4. Troubleshooting Path

If you encounter issues:
1.  Check the [Troubleshooting Guide](../dev-guides/troubleshooting.md).
2.  Review documentation for the specific module or feature causing problems. (See section 6 for a full list).
3.  Examine the [Changelog](../maintenance/changelog.md) for recent relevant changes.

## 5. Project History Query

To understand the evolution of the project:
1.  Review the [Changelog](../maintenance/changelog.md).
2.  Browse the `docs_old/archive/` directory for historical design documents and decisions (Note: this content is from the previous documentation structure and may be outdated).
