# Optional developer source

`elmtui-dev.asd` owns `dev.lisp` (diagnostics/native view previews) and
`benchmark.lisp` (synchronous microbenchmarks). Tests live in `tests/dev-tests.lisp`
and `tests/dev/benchmark-tests.lisp`, owned by `elmtui-dev-tests.asd`.

See [the developer guide](../../docs/developer-tools.md) for usage, measured
contracts, limitations and the inventory of retained, unloaded legacy tools.
