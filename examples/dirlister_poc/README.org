* DirLister PoC - Terminal User Interface Application

** Overview
The `DirLister PoC` is a Terminal User Interface (TUI) application built using the `elmtui` library. It allows users to navigate directories and view their contents in a listbox-style interface.

** Features
- Navigate directories interactively.
- Display directory contents in a listbox.
- Handle terminal resize events dynamically.
- Quit the application gracefully.

** Architecture
The application follows the TEA (The Elm Architecture) pattern:
- **Model**: Represents the application state.
- **Update**: Handles messages and updates the state.
- **View**: Generates the UI tree for rendering.
- **Subscriptions**: Specifies the events the application listens to.

** Data Flow
1. **Initialization**:
   - The `dirlister-init-fn` initializes the application state, including the current directory and listbox items.
2. **Event Handling**:
   - Events such as `:listbox-item-selected`, `:terminal-resized`, and `:app-quit-requested` are processed by the `dirlister-update-fn`.
   - The state is updated based on the event type.
3. **Rendering**:
   - The `dirlister-view-fn` generates the UI tree based on the current state.
   - The UI is rendered using the `elmtui` library's rendering functions.

** Usage
1. Ensure the `elmtui` library is installed and available.
2. Load the `dirlister_poc.asd` system:
   ```lisp
   (ql:quickload "dirlister_poc")
   ```
3. Start the application:
   ```lisp
   (dirlister_poc:start-dirlister-poc)
   ```

** Implementation Details
- **Model**:
  - Stores the current directory, listbox state, terminal dimensions, and status messages.
- **Update**:
  - Handles directory navigation, terminal resize events, and quit requests.
- **View**:
  - Displays the listbox and any status messages.
- **Subscriptions**:
  - Listens for user interactions and system events.
